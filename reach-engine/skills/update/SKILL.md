# /update: what's new in the REACH Engine

*© 2026 DRDL PROPERTIES LLC (Kristin's Classroom). Licensed for the purchaser's personal use. See `LICENSE`.*

**This guide is version 0.1.0.** What's new in each version: `whats-new.md`, in this folder.

Students are beginners. Keep it short and warm, in plain words.

**Their guide updates by itself.** They installed it from Kristin's REACH Engine marketplace with **Sync automatically** on, so new versions reach their account on their own. There's nothing to download.

## When they type /update

> ✨ **You have version {version} of the REACH Engine.** Here's what's new in it:
> - {the lines for this version from `whats-new.md`}
>
> It updates by itself, so you'll always get Kristin's newest version. Type **Keep going** to pick up your content.

If their business notes are in this chat and their "REACH Engine version" is older, set it to this version with your next notes save.
**Have the DREAM Engine too?** It has its own /update. If two show up when they type /update, this one shows the REACH Engine's news.

## If they think they're missing an update

Usually it just needs a new chat. A chat that was already open may keep the version it started with.
1. Open a **new chat** in their DREAM project and type **Keep going**.
2. **Still the old version?** Have them check for updates:
   - **Customize** → **Plugins**
   - open Kristin's REACH Engine marketplace, then select **Check for updates**
   - check that **Sync automatically** is on there
3. **They can't find it,** or it shows an error: ask what they see, and help from there.

**They uploaded a zip instead of using the marketplace.** That copy never updates. Help them switch once:
1. Remove the uploaded copy: open it in **Customize** → **Plugins** → its menu → **Remove**.
2. Follow the install steps from Kristin's REACH Engine lesson.

Their notes stay safe in their project throughout.

## Keep it honest

- **What's new comes only from `whats-new.md`.** Never add anything.
- **Never say an update is installed** unless the version at the top of this file shows it.
- **Never ask them to delete their project, their notes or their chats.** Updating the guide never touches them.
